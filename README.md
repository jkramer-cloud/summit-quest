# Summit Quest: The Endless Ascent

**Version 1.0** · Educational vertical platformer · Grades 5–8

Play: https://jkramer-cloud.github.io/summit-quest/ (after deployment)

Climb endless randomized routes through six environments, use seven types of boost pads, transfer momentum through blue and orange portals, avoid creatures and traps, unlock checkpoints and treasures, and collect cosmetics and achievements. Learning questions power the adventure.

## Getting started

Open `index.html` in a modern browser. All gameplay, maps and questions are embedded in the file; no server, accounts, API key, external libraries or network connection are required for gameplay. GitHub Pages is recommended for a consistent browser origin.

## Controls

| Action | Keys |
|---|---|
| Move / steer in flight | A/D or left/right arrows |
| Jump | Space, W or up arrow; hold for height |
| Double jump | Press jump again in midair |
| Interact with camp/chest | E |
| Return to active camp after major fall | C |
| Equip/stow portal gun after unlock | Q |
| Aim and place portals | Mouse, left click blue, right click orange (or Shift + left click) |
| Clear personal portals | R |
| Outfitter | B |
| Journal | M |
| Pause | Esc or P |

## Learning

Select grade 5–8 and subject in Settings. Math, ELA, U.S. geography (states, capitals and highlighted maps), science and technology are available. Geography supports typed or multiple-choice answers. Correct answers restore 10 energy (maximum 30); normal jumps cost 1, double jumps and portal placements cost 2. Timed learning gates remain active even when using free boosts and portals. Incorrect answers require feedback and a same-skill retry; repeated rapid incorrect responses trigger warnings and escalating local restrictions. Academic Practice remains available without adventure rewards. Response speed is not proof of misconduct.

## Data and limitations

Records, coins, cosmetics, learning history and restrictions are stored in browser localStorage. They do not sync between devices; clearing browser storage can erase them. A downloaded file and a hosted page may have different storage. Settings and restrictions are not tamper-proof and are not a secure gradebook. Checkpoints belong to a current expedition. Audio is optional and off by default. Physical Chromebook classroom testing is recommended.

## Geography attribution

Simplified U.S. state outlines derived from [Vega datasets `us-10m.json`](https://github.com/vega/vega-datasets/blob/main/data/us-10m.json), based on U.S. Census geographic data. Alaska and Hawaii are shown as repositioned insets, not to scale.

## GitHub Pages

Create a public repository named `summit-quest`. Upload `index.html`, `README.md`, and `.nojekyll` at the root of `main`. In Settings → Pages select Deploy from a branch, `main`, `/ (root)`.
